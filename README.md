# Laravel + Vue Starter Kit

## Introduction

A personal Laravel starter kit for building modern web applications with Laravel, Vue, and Inertia.

This starter kit provides a clean foundation for quickly starting a new Laravel application without repeating the same initial setup and configuration every time.

It uses **Vue 3**, the **Composition API**, **TypeScript**, **Tailwind CSS**, and **Inertia.js**, combining Laravel's server-side routing and controllers with a modern Vue frontend.

## What's Included

In addition to the standard Laravel + Vue setup, this starter kit includes:

* **Vue 3 + Inertia.js**
* **TypeScript**
* **Tailwind CSS**
* **Pest** for testing
* **Laravel Boost** for improved development workflow
* **Unguarded Eloquent models** by default
* Reusable **Modal component**
* Reusable **Pagination component**
* Preconfigured development and setup commands

### Composer Scripts

The following Composer commands are available:

```bash
# Run the test suite
composer test

# Start the development environment
composer dev

# Install and configure the application
composer setup
```

## Getting Started

Clone the repository and run the setup command:

```bash
composer setup
```

After setup is complete, start the development environment with:

```bash
composer dev
```

To run the test suite:

```bash
composer test
```
